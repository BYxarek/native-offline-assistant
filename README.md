# Сфера

Нативное приложение WinUI 3 для потоковой расшифровки русской речи в чате. Распознавание выполняется офлайн.

## Запуск

Нужны Windows 10/11, .NET SDK 10 и доступ к микрофону в параметрах конфиденциальности Windows.

```powershell
dotnet run --project .\OfflineAssistant\OfflineAssistant.csproj --property:Platform=x64
```

По умолчанию приложение слушает в фоне и ждёт слово «сфера». В настройках можно выбрать горячую клавишу, показ сферы в углу и время ожидания следующей фразы. Закрытие окна скрывает его в трей; выход доступен на странице настроек. Распознанные фразы сохраняются в чате до завершения процесса.

## Установщик

На компьютере с Inno Setup 6 и [uv](https://docs.astral.sh/uv/) выполните `installer\Build-Installer.ps1`. При первой сборке скрипт загрузит Python 3.12, PyTorch и модель Silero, затем включит их в инсталлер. Готовый файл появится в `installer\output`. После установки Сфера запускается вместе с Windows в фоне; значок в трее открывает окно.

Версии задаются в `OfflineAssistant\OfflineAssistant.csproj`: `Version` отображается пользователю (`0.2.0`), `BuildNumber` — семизначный внутренний номер (`0000009`). При новой сборке увеличивайте `BuildNumber`; установщик включает оба значения в имя файла.

При запуске приложение создаёт `sphere.log` рядом с установленным `OfflineAssistant.exe` и записывает туда предупреждения и ошибки с временем и подробностями исключений.

Модель [alphacep/vosk-model-streaming-ru](https://huggingface.co/alphacep/vosk-model-streaming-ru), версия 0.56, лицензия Apache-2.0. В проект включены ее INT8 ONNX-файлы. Для этого формата используется [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx); классический Vosk API с ним несовместим. Тест модели:

```powershell
dotnet run --project .\checks\ModelCheck\ModelCheck.csproj
```

Первая версия сохраняет фразы в чате только на время работы приложения. Ответы ИИ и выполнение голосовых команд пока не реализованы.

На странице «Фразы» можно озвучить текст моделью [Silero v5_5_ru](https://github.com/snakers4/silero-models), выбрать один из пяти голосов, прослушать сохранённые записи и удалить их. Записи хранятся в `%LOCALAPPDATA%\Sphere\phrases` и работают без сети. Лицензия модели — CC BY-NC-SA 4.0; коммерческое использование не разрешено условиями модели.
